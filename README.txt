TECHNOVA — Các trang HTML con

Mở thư mục này trong VS Code. Mỗi trang là một file HTML độc lập, có CSS inline để dễ chỉnh sửa.

Các trang chính:
- index.html: trang chủ
- catalog.html: toàn bộ catalog 18 sản phẩm
- macbook.html, iphone.html, airpods.html, ipad.html, apple-watch.html, accessories.html
- about.html: câu chuyện và video
- support.html: thông tin hỗ trợ
- reviews.html: nhận xét khách hàng
- contact.html: liên hệ shop
- payment.html: phương thức thanh toán
- cart.html: giỏ hàng mô phỏng

Chạy bằng VS Code Live Server hoặc:
python3 -m http.server 8080

Video dùng đường dẫn tương đối technova-apple-ad.mp4.


Trang chi tiết sản phẩm:
- Mỗi sản phẩm có một file riêng trong thư mục products/.
- Các card sản phẩm đã được liên kết đến trang chi tiết.
- Trang chi tiết có chọn màu, RAM/bộ nhớ, số lượng, thêm giỏ và nút thanh toán demo.
